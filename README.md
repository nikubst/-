# ربات تلگرام دو منظوره: سیستم استخدام و جذب نیرو + کاتالوگ و بازاریابی هوشمند

این ربات به صورت تخصصی برای کسب‌وکارهای حوزه‌های تولیدی، صنایع‌دستی، فرش و تابلوفرش طراحی شده است تا فرآیندهای استخدام و فروش را به شکل خودکار و دقیق مدیریت نماید.

---

## 🌟 ویژگی‌های کلیدی سیستم

### ۱. بخش استخدام و جذب نیرو (HR & Recruitment)
* **قوانین و ضوابط:** نمایش شرایط استخدام و دریافت تأییدیه رسمی از متقاضی.
* **فرم‌ساز چندمرحله‌ای:** دریافت نام، سن، شماره تماس (متنی یا ارسال خودکار از تلگرام)، کدملی، شهر سکونت، موقعیت شغلی، سوابق و مهارت‌ها.
* **دریافت و دسته‌بندی مدارک:** امکان بارگذاری چندگانه عکس‌ها و اسناد هویتی (کارت ملی، شناسنامه، رزومه، نمونه‌کارها).
* **کد پیگیری اختصاصی:** صدور شناسه پیگیری یکتا (مانند `HR-84921`) برای هر متقاضی.
* **کارتابل اختصاصی ادمین:**
  - دریافت فوری پیام آلارم به همراه دکمه‌های شیشه‌ای عملیاتی:
  - `[✅ تأیید استخدام]` -> تغییر وضعیت و ارسال پیام تبریک و دعوت به مصاحبه برای متقاضی.
  - `[❌ رد درخواست]` -> ثبت پیام عدم پذیرش و اطلاع به متقاضی.
  - `[⚠️ اعلام نقص مدرک]` -> ثبت توضیحات نقص مدرک و فعال شدن دکمه آپلود مجدد مدارک در پنل متقاضی.
  - `[📂 مشاهده مدارک ارسالی]` -> نمایش تمامی فایل‌ها و عکس‌های ارسالی کارجو.

### ۲. بخش کاتالوگ و بازاریابی (Marketing & Affiliate)
* **مشخصات فنی و تخصصی هر اثر:**
  - عنوان و کد کالا
  - ابعاد و اندازه دقیق (مثال: ۲ در ۳ متر)
  - **رج‌شمار** (مثال: ۵۰ رج، ۶۰ رج اعلا)
  - **نام نقشه و طرح** (مثال: خطیبی، لچک ترنج، مینیاتور استاد فرشچیان)
  - جنس چله و الیاف (ابریشم، مرینوس و...)
  - قیمت به تومان
  - **نکات طلایی و سناریوی پیشنهادی بازاریابی** برای متقاعدسازی مشتریان
* **پنل و کد اختصاصی بازاریاب:**
  - صدور دیپ‌لینک اختصاصی تلگرام: `t.me/YourBot?start=ref_M1001`
  - ثبت اتوماتیک مشتریان معرفی‌شده به نام بازاریاب در دیتابیس
  - کارنامه زنده: تعداد ورودی‌ها، تعداد فروش‌های قطعی، درصد و مجموع پورسانت دریافتی
* **پکیج آماده انتشار:** بازاریاب با زدن دکمه «دریافت پکیج بازاریابی» متن حرفه‌ای فروش + عکس‌های باکیفیت بدون قیمت را دریافت می‌کند تا در شبکه‌های اجتماعی منتشر کند.

## 🛠️ راهنمای راه‌اندازی و اجرا

### گام اول: دریافت توکن و آیدی عددی
1. در تلگرام به ربات **[@BotFather](https://t.me/BotFather)** رفته و دستور `/newbot` را بزنید تا توکن ربات را دریافت کنید.
2. به ربات **[@userinfobot](https://t.me/userinfobot)** پیام دهید تا **شناسه عددی (Id)** اکانت تلگرام خود را دریافت نمایید.

### گام دوم: تنظیم فایل پیکربندی (`.env`)
فایل `.env` را در پوشه اصلی پروژه باز کرده و مقادیر زیر را قرار دهید:
```env
BOT_TOKEN=توکن_دریافتی_از_بات_فادر
ADMIN_IDS=شناسه_عددی_ادمین_شما
DATABASE_URL=sqlite+aiosqlite:///bot_database.db
BUSINESS_NAME=مجموعه فرش و صنایع دستی
```

### گام سوم: نصب نیازمندی‌ها و اجرای ربات
```bash
# ایجاد محیط مجازی (اختیاری)
python3 -m venv .venv
source .venv/bin/activate

# نصب پکیج‌ها
pip install -r requirements-bot.txt

# اجرای تست‌های اعتبارسنجی سیستم
python3 test_system.py

# اجرای نهایی ربات
python3 main.py
```

## 📂 ساختار فایل‌های پروژه

```
robot/
├── .env                       # فایل تنظیمات محرمانه (توکن و ادمین‌ها)
├── config.py                  # اعتبارسنجی تنظیمات با Pydantic
├── main.py                    # فایل اصلی راه‌اندازی و کنترلر Aiogram
├── test_system.py             # اسکریپت تست و اعتبارسنجی خودکار پایگاه‌داده
├── requirements.txt           # لیست وابستگی‌ها
├── database/
│   ├── models.py              # مدل‌های User, JobApplication, Product, Marketer
│   └── session.py             # موتور ارتباط غیرهمگام با دیتابیس (SQLAlchemy)
├── handlers/
│   ├── common.py              # منوی اصلی، استارت و رفرال
│   ├── recruitment.py         # فرآیند کامل استخدام، دریافت مدارک و رهگیری
│   ├── marketing.py           # کاتالوگ محصولات، پنل بازاریاب و پکیج فروش
│   └── admin.py               # کارتابل بررسی مدارک، افزودن محصول و پیام همگانی
├── keyboards/
│   ├── reply.py               # منوهای کاربری فارسی
│   ├── inline.py              # دکمه‌های شیشه‌ای بررسی و ناوبری کاتالوگ
│   └── admin_kb.py            # کیبوردهای مدیریت سیستم
├── middlewares/
│   └── db_middleware.py       # تزریق Session دیتابیس به تمامی رویدادها
└── utils/
    └── states.py              # مراحل فرم‌ها بر پایه FSM
```
